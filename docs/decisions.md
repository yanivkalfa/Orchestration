# Decisions — the rulings ledger

Every owner ruling, in full. `docs/orchestration.md` "Standing rulings" carries the one-line
form with the same number. Append only: never rewrite an entry. A change is a new entry that
names the one it amends.

## Entry shape

```
## §<n> — <short title> (<YYYY-MM-DD HH:MM>)

**The owner's words.** "<exact quote>"

**The question.** <what was asked; the options offered, (A)/(B), and the recommendation>

**The ruling.** <what is now true>

**Evidence.** <measurements, files, commits that informed it>

**Amends.** <§m, or "none">

**Lands in.** <the row or commit that applies it, or "rule only">
```
